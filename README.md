# cursoemvideo
Repositório com exercícios e desafios desenvolvidos durante os cursos de HTML5, CSS3 e JavaScript do Curso em Vídeo.

## Cursos

### HTML5 e CSS3

Curso de HTML5 e CSS3 com foco na criação de páginas web, abordando desde os fundamentos da estrutura e estilização até recursos como multimídia, tabelas, formulários, iframes, Git e GitHub, publicação de sites e desenvolvimento responsivo com media queries e mobile first.

Desafios desenvolvidos durante o curso:

- [Desafio 01 - Android](https://lucass-ferreira.github.io/cursoemvideo/html-css/desafios/desafio-007/site.html)
- [Desafio 02 - Cordel](https://lucass-ferreira.github.io/cursoemvideo/html-css/desafios/desafio-008/cordel.html)
- [Desafio 03 - Social](https://lucass-ferreira.github.io/cursoemvideo/html-css/desafios/desafio-010/projeto-social.html)
- [Desafio 04 - Login](https://lucass-ferreira.github.io/cursoemvideo/html-css/desafios/desafio-011/projeto-login.html)

### JavaScript

Curso de JavaScript com foco em lógica de programação, criação de scripts, funções, manipulação do DOM e desenvolvimento de páginas web interativas.

Desafios desenvolvidos durante o curso:

- [Desafio 01 - Hora do Dia](https://lucass-ferreira.github.io/cursoemvideo/javascript/desafios/desafio-001/horas.html)
- [Desafio 02 - Verificador de Idade](https://lucass-ferreira.github.io/cursoemvideo/javascript/desafios/desafio-002/idade.html)
- [Desafio 03 - Contador](https://lucass-ferreira.github.io/cursoemvideo/javascript/desafios/desafio-003/contador.html)
- [Desafio 04 - Tabuada](https://lucass-ferreira.github.io/cursoemvideo/javascript/desafios/desafio-004/tabuada.html)
- [Desafio 05 - Analisador de Números](https://lucass-ferreira.github.io/cursoemvideo/javascript/desafios/desafio-005/analisador.html)
